Archive

기출 문항 및 학습 자료 DB에서 문항을 검색·조회하는 API입니다.

  • 연도 · 시험 · 과목 · 문항 번호 · 정답률 등의 조건으로 검색할 수 있습니다.
  • 필드로 표현하기 어려운 조건은 문장으로 덧붙일 수 있습니다.
  • 보유한 Question 객체와 유사한 문항을 유사도 순으로 조회할 수 있습니다.
  • 검색 결과의 item_id로 Pipeline과 같은 Question 객체를 조회할 수 있습니다.
  • 시험지 단위로 등급컷과 난이도 통계를 조회할 수 있습니다.

개요

조건으로 문항을 찾고, 필요한 문항의 item_id로 원본 객체를 받는 흐름입니다.

from kdsnr_ai import Client
from kdsnr_ai.archive import (
    Collection,
    Course,
    Exam,
    QuestionFilter,
    QuestionSearchResult,
)

client = Client(api_key="YOUR_API_KEY")

result: QuestionSearchResult = client.archive.search_questions(
    query="삼차함수 그래프와 접선의 개수를 묻는 문항",
    filters=QuestionFilter(
        collection=Collection.KICE,
        year=2025,
        exam=Exam.CSAT,
        course=Course.CALCULUS,
        correct_rate_max=0.4,
    ),
    limit=5,
    offset=0,
)

for item in result.items:
    print(item.item_id, item.question_numbers, item.relevance)
메서드역할
search_questions정해진 필드로 범위를 좁히고, 문장 조건이 있으면 그 조건에 가까운 문항 순으로 반환합니다.
get_questionitem_id로 문항 원본을 가져옵니다. 단독 문항이면 ArchivedQuestion, 지문 세트면 ArchivedQuestionSet입니다.
find_similar_questions입력한 Question 객체와 유사한 문항을 유사도 순으로 반환합니다.
list_exams조건에 맞는 시험지 목록을 등급컷 · 난이도 통계와 함께 반환합니다.
  • 조건으로 — 연도 · 시험 · 과목 · 정답률처럼 필드가 정해진 조건은 filters에 지정합니다.
  • 문장으로 — 필드로 표현하기 어려운 조건은 query에 문장으로 지정합니다. filters 없이 query만 전달해도 됩니다.
  • 문항으로 — 보유한 Question 객체와 유사한 문항은 find_similar_questions로 검색합니다.

API 사용법

search_questions

조건에 맞는 문항 요약을 반환합니다.

from kdsnr_ai import Client
from kdsnr_ai.archive import (
    Collection,
    Course,
    Curriculum,
    Difficulty,
    Exam,
    Grade,
    QuestionFilter,
    QuestionSearchResult,
    QuestionType,
    Recall,
    Subject,
)

client = Client(api_key="YOUR_API_KEY")

result: QuestionSearchResult = client.archive.search_questions(
    query="삼차함수 그래프가 있고 접선의 개수를 묻는 문항",
    filters=QuestionFilter(
        collection=Collection.KICE,
        year=2025,
        exam=Exam.CSAT,
        round=None,
        course=Course.CALCULUS,
        curriculum=Curriculum.REVISED_2015,
        grade=Grade.HIGH_3,
        subject=Subject.MATH,
        label=None,
        question_type=QuestionType.QUESTION,
        question_number=None,
        unit=None,
        keyword=None,
        difficulty=Difficulty.HIGH,
        has_figure=True,
        has_table=None,
        has_equation=True,
        correct_rate_min=None,
        correct_rate_max=0.4,
        facets=None,
    ),
    recall=Recall.AUTO,
    limit=50,
    offset=0,
)
인자타입기본값설명
querystr | NoneNone필드로 표현하기 어려운 조건을 문장으로 지정합니다.
filtersQuestionFilter | NoneNone연도 · 시험 · 과목 · 정답률처럼 필드로 거는 조건입니다.
recallRecallRecall.AUTOquery를 쓸 때 어떤 문항부터 읽어 볼지 정하는 방식입니다. query가 없으면 쓰이지 않습니다.

offsetint0전체 결과에서 건너뛸 문항 수입니다.

  • query가 있으면 문장에 가까운 순서로, 없으면 최근 저장된 순서로 반환합니다.

자연어 필터

from kdsnr_ai import Client
from kdsnr_ai.archive import Course, QuestionFilter, QuestionSearchResult

client = Client(api_key="YOUR_API_KEY")

result: QuestionSearchResult = client.archive.search_questions(
    query="그래프가 두 개 제시되고 두 함수의 교점 개수를 묻는 문항",
    filters=QuestionFilter(
        course=Course.CALCULUS,
        has_figure=True,
    ),
    limit=5,
    offset=0,
)
  • filters 없이 query만 지정해도 됩니다. 문장에 적힌 연도 · 시험 · 과목은 서버가 필터로 옮깁니다.
  • relevance는 확률이 아닙니다. "0.8 이상이면 채택" 같은 기준으로 사용하지 않고, 같은 결과 안의 순서를 볼 때만 사용합니다.
  • 판정 모델에 장애가 있으면 정렬을 생략하고 반환합니다. 이때 relevance가 붙지 않습니다.
recall후보 선정 방식쓰는 경우
Recall.AUTO문장에 적힌 조건을 필터로 옮기고, 그래도 남은 문항이 많지 않으면 전부 판정합니다.기본값. 대부분 그대로 두면 됩니다.
Recall.VECTOR조건을 해석하지 않고 문장과 의미가 가까운 문항 순으로 선정합니다.조건 없이 내용만으로 넓게 훑을 때.
Recall.INDEXfilters에 맞는 문항을 최근 저장된 순서로 앞에서부터 선정합니다.filters로 이미 좁혔고 그 안을 빠짐없이 훑을 때.

정답률 필터와 지문 세트

  • 지문 세트는 속한 문항 하나만 조건에 맞아도 검색됩니다.
  • 따라서 correct_rate_max=0.3으로 검색된 지문 세트는 세트 전체가 어려웠다는 의미가 아니라, 그 안에 정답률 30% 이하인 문항이 하나 이상 있다는 의미입니다.
  • 어느 문항이 조건에 맞았는지는 curation.questions의 문항 번호별 correct_rate로 확인합니다.

find_similar_questions

입력한 Question 객체와 유사한 문항을 유사도 순으로 반환합니다.

from kdsnr_ai import Client
from kdsnr_ai.archive import Course, QuestionFilter, SimilaritySearchResult

client = Client(api_key="YOUR_API_KEY")

question = client.archive.get_question(
    item_id="ARCHIVE_ITEM_ID",
    include_image=False,
)

result: SimilaritySearchResult = client.archive.find_similar_questions(
    question=question,
    question_number=None,
    query="DNA 상대량 표를 함께 제시하는 문항",
    filters=QuestionFilter(
        course=Course.CALCULUS,
    ),
    limit=5,
)

for item in result.items:
    print(item.item_id, item.similarity)
인자타입기본값설명
questionQuestion | QuestionSet—기준으로 삼을 Question 객체입니다.
question_numberint | NoneNone지문 세트 안에서 기준으로 삼을 문항 번호입니다. QuestionSet을 입력할 때는 반드시 지정해야 합니다.
querystr | NoneNone유사 문항 중에서 다시 제외할 조건을 문장으로 지정합니다.
filtersQuestionFilter | NoneNone유사 문항을 검색할 범위를 좁히는 조건입니다.
limitint5반환할 문항 수입니다. 1~20 사이로 지정합니다.
  • query를 함께 지정하면 유사도 순서는 유지한 채 조건에 맞지 않는 문항이 결과에서 제외됩니다.
  • 판정 모델에 장애가 있으면 이 제외 과정을 생략하고 유사도 순서 그대로 반환합니다.
  • 입력한 문항 자체는 결과에서 제외됩니다.
  • Pipeline이 추출한 Question 객체에 q_img가 없으면 그림 · 수식 · 지면 배치를 비교하지 못해 정확도가 떨어집니다.
  • Archive에서 조회한 문항은 서버가 저장해 둔 이미지를 사용합니다.

list_exams

조건에 맞는 시험지 목록을 등급컷 · 난이도 통계와 함께 반환합니다.

from kdsnr_ai import Client
from kdsnr_ai.archive import (
    Collection,
    Course,
    Exam,
    ExamFilter,
    ExamListResult,
)

client = Client(api_key="YOUR_API_KEY")

result: ExamListResult = client.archive.list_exams(
    filters=ExamFilter(
        collection=Collection.KICE,
        year=None,
        exam=Exam.CSAT,
        round=None,
        course=Course.CHEMISTRY_1,
        curriculum=None,
        grade=None,
        label=None,
    ),
    has_cuts=True,
    limit=50,
    offset=0,
)

for exam in result.items:
    print(exam.label, exam.stats.cuts[1].standard_score, exam.derived.rate_mean)
인자타입기본값설명

has_cutsbool | NoneNoneTrue면 등급컷이 입력된 시험지만 반환합니다.
limitint50반환할 최대 시험지 수입니다.
offsetint0전체 결과에서 건너뛸 시험지 수입니다.

시험지끼리 난이도 비교하기

  • 등급컷은 exam이 같은 시험지끼리만 비교합니다. 응시 집단이 다르면 같은 점수의 뜻이 달라집니다.
  • 2025학년도 수능과 2026학년도 수능처럼 exam이 같고 year만 다른 시험지는 만점 표준점수(stats.perfect_score.standard_score)로 비교합니다. 시험이 어려울수록 높아집니다.
  • exam이 다른 시험지끼리는 derived로 비교합니다. 정답률의 평균 · 분포는 응시 집단과 무관합니다.
  • rate_count가 question_count보다 작으면 일부 문항만 계산한 값입니다.
  • 2022학년도부터의 국어 · 수학 등급컷은 선택과목 구분 없이 매겨져, 같은 시험의 공통 · 선택 시험지에 같은 값이 실립니다(note에 표시).
