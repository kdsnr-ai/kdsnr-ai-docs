Archive

기출 문항 및 학습 자료 DB에서 문항을 검색·조회하는 API입니다.

  • 연도 · 시험 · 과목 · 문항 번호 · 정답률 등의 조건으로 검색할 수 있습니다.
  • 정해진 필드로 표현하기 어려운 검색 조건을 자연어 필터로 추가할 수 있습니다.
  • Question 객체와 유사한 문항을 유사도 순으로 확인할 수 있습니다.
  • 검색 결과의 item_id로 Pipeline과 같은 Question 객체를 조회할 수 있습니다.

개요

조건으로 문항을 찾고, 필요한 문항의 item_id로 원본 객체를 받는 흐름입니다.

from kdsnr_ai import Client
from kdsnr_ai.archive import (
    Collection,
    Course,
    Exam,
    QuestionFilter,
    QuestionSearchResult,
)

client = Client(api_key="YOUR_API_KEY")

result: QuestionSearchResult = client.archive.search_questions(
    query="삼차함수 그래프와 접선의 개수를 묻는 문항",
    filters=QuestionFilter(
        collection=Collection.KICE,
        year=2025,
        exam=Exam.CSAT,
        course=Course.CALCULUS,
        correct_rate_max=0.4,
    ),
    limit=5,
    offset=0,
)

for item in result.items:
    print(item.item_id, item.question_numbers, item.relevance)
메서드역할
search_questions정해진 필드로 문항 범위를 제한하고, 자연어 필터가 있으면 해당 조건에 가까운 순서로 반환합니다.
get_questionitem_id에 해당하는 ArchivedQuestion | ArchivedQuestionSet 원본을 반환합니다.
find_similar_questions입력한 Question 객체와 유사한 SimilarQuestion 목록을 유사도 순으로 반환합니다.
  • 조건으로 — 연도 · 시험 · 과목 · 정답률처럼 필드가 정해진 조건은 filters에 넣습니다.
  • 문장으로 — 필드로 표현하기 어려운 조건은 query에 문장으로 적습니다. filters 없이 query만 넘겨도 됩니다.
  • 문항으로 — 가지고 있는 Question 객체와 비슷한 문항은 find_similar_questions로 찾습니다.

API 사용법

search_questions

조건에 맞는 문항 요약을 반환합니다.

from kdsnr_ai import Client
from kdsnr_ai.archive import (
    Collection,
    Course,
    Curriculum,
    Difficulty,
    Exam,
    Grade,
    MaterialForm,
    QuestionFilter,
    QuestionSearchResult,
    QuestionType,
    Recall,
    Subject,
)

client = Client(api_key="YOUR_API_KEY")

result: QuestionSearchResult = client.archive.search_questions(
    query="삼차함수 그래프가 있고 접선의 개수를 묻는 문항",
    filters=QuestionFilter(
        collection=Collection.KICE,
        year=2025,
        exam=Exam.CSAT,
        round=None,
        course=Course.CALCULUS,
        curriculum=Curriculum.REVISED_2015,
        grade=Grade.HIGH_3,
        subject=Subject.MATH,
        label=None,
        question_type=QuestionType.QUESTION,
        question_number=None,
        unit=None,
        keyword=None,
        difficulty=Difficulty.HIGH,
        status=MaterialForm.PRINTED,
        has_figure=True,
        has_table=None,
        has_equation=True,
        correct_rate_min=None,
        correct_rate_max=0.4,
        facets=None,
    ),
    recall=Recall.AUTO,
    limit=50,
    offset=0,
)
인자타입기본값설명
querystr | NoneNone정해진 필드만으로 표현하기 어려운 조건을 자연어로 작성하는 필터입니다.
filtersQuestionFilter | NoneNone연도 · 시험 · 과목 · 정답률처럼 필드가 정해진 검색 조건입니다.
recallRecallRecall.AUTOquery를 쓸 때 후보 문항을 고르는 방식입니다. query가 없으면 무시됩니다.
limitint50반환할 최대 문항 수입니다.
offsetint0전체 결과에서 건너뛸 문항 수입니다.
  • 모든 조건은 AND이고, filters의 필드는 자유롭게 조합할 수 있습니다.
  • query가 있으면 문장에 가까운 순서로, 없으면 최근 저장된 순서로 반환합니다.

자연어 필터

from kdsnr_ai import Client
from kdsnr_ai.archive import Course, QuestionFilter, QuestionSearchResult

client = Client(api_key="YOUR_API_KEY")

result: QuestionSearchResult = client.archive.search_questions(
    query="그래프가 두 개 제시되고 두 함수의 교점 개수를 묻는 문항",
    filters=QuestionFilter(
        course=Course.CALCULUS,
        has_figure=True,
    ),
    limit=5,
    offset=0,
)
  • filters 없이 query만 써도 됩니다. 문장에 적힌 연도 · 시험 · 과목은 서버가 필터로 옮깁니다.
  • relevance는 확률이 아닙니다. 통과 기준으로 쓰지 않고 같은 결과 안의 정렬에만 씁니다.
recall후보 선정 방식쓰는 경우
Recall.AUTO질의에 적힌 조건을 필터로 옮기고, 좁혀진 범위가 상한 이하면 전량 판정합니다.기본값. 대부분 그대로 두면 됩니다.
Recall.VECTOR조건 해석 없이 질의와 의미가 가까운 순서로만 후보를 고릅니다.조건 없이 내용만으로 넓게 훑을 때.
Recall.INDEXfilters에 맞는 문항 중 최근 저장된 순서로 앞부분만 봅니다.filters로 이미 좁혔고 그 안을 빠짐없이 훑을 때.

정답률 필터와 지문 세트

  • 지문 세트는 소속 문항 중 하나라도 범위에 들면 결과에 나옵니다. correct_rate_max=0.3은 "이 항목의 정답률이 30% 이하"가 아니라 "여기에 정답률 30% 이하인 문항이 있음"입니다.
  • 세트 안에서 어느 문항이 조건에 맞았는지는 curation.questions의 문항번호별 correct_rate로 확인합니다.

get_question

검색 결과의 item_id로 원본 Question 객체를 반환합니다.

from kdsnr_ai import Client
from kdsnr_ai.archive import ArchivedQuestion, ArchivedQuestionSet

client = Client(api_key="YOUR_API_KEY")

question: ArchivedQuestion | ArchivedQuestionSet = client.archive.get_question(
    item_id="ARCHIVE_ITEM_ID",
    include_image=False,
)

client.pipeline.compose_hwpx(
    [question],
    "out/hwpx",
)
인자타입기본값설명
item_idstr—QuestionSummary.item_id에 해당하는 문항 식별자입니다.
include_imageboolFalseTrue이면 100dpi WebP 문항 이미지인 q_img를 포함합니다. 응답 크기가 수백 KB까지 커질 수 있습니다.
  • ArchivedQuestion · ArchivedQuestionSet은 Pipeline의 Question · QuestionSet 필드를 그대로 가지고, 여기에 item_id와 curation이 더해집니다.
  • 반환값은 compose_hwpx · find_similar_questions처럼 Question 객체를 받는 메서드에 그대로 넘길 수 있습니다.

find_similar_questions

입력한 Question 객체와 유사한 문항을 유사도 순으로 반환합니다.

from kdsnr_ai import Client
from kdsnr_ai.archive import Course, QuestionFilter, SimilaritySearchResult

client = Client(api_key="YOUR_API_KEY")

question = client.archive.get_question(
    item_id="ARCHIVE_ITEM_ID",
    include_image=False,
)

result: SimilaritySearchResult = client.archive.find_similar_questions(
    question=question,
    question_number=None,
    query="DNA 상대량 표를 함께 제시하는 문항",
    filters=QuestionFilter(
        course=Course.CALCULUS,
    ),
    limit=5,
)
