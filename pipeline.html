Pipeline

PDF·HWP·HWPX 문서에서 문항을 추출하고, Question 객체와 필요한 출력 파일을 만드는 API입니다.

  • 입력 : 문항이 포함된 문서 파일 (hwp, hwpx, pdf)
  • 출력 : Question 객체, 문항 이미지, 선택한 미리보기 파일, hwpx
  • 원문 수식, 표, 이미지, 도식, 밑줄, 굵은 글씨, 박스 보존
  • 2단 구조 또는 페이지에 걸친 문항을 자동 복원

개요

from pathlib import Path

from kdsnr_ai import Client, EmitPreviewConfig, ExtractResult

client = Client(api_key="YOUR_API_KEY")

doc = client.pipeline.import_file("exam.pdf", label="exam_2026")
result: ExtractResult = client.pipeline.extract_question(
    doc,
    subject="auto",
    emit_preview=EmitPreviewConfig(
        format="png",
        dpi=300,
    ),
)

questions = result.questions
for preview in result.previews:
    preview.save(Path("out/preview") / preview.filename)
메서드역할
import_file파일 업로드 → Document
extract_questionpdf · hwp · hwpx → Question 리스트, 선택 시 미리보기 파일 함께 반환
compose_hwpxQuestion 리스트 → 문항별 한글 문서(hwpx)
hwp_to_pdfhwp · hwpx → pdf (원본 조판 보존)
hwp_to_hwpxhwp → hwpx

extract_question이 반환하는 Question 리스트는 JSON으로 직렬화되고, 저장 · 수정 · 직접 작성할 수 있습니다. EmitPreviewConfig 사용 여부와 관계없이, 파이프라인이 추출한 각 Question에는 100dpi WebP 이미지가 q_img 필드로 삽입됩니다.

Question 스키마

extract_question은 문서를 문항 단위로 잘라 객체 리스트로 반환합니다. 단독 문항은 Question 하나가 되고, 하나의 지문에 여러 문항이 묶인 세트는 지시문·지문·문항들을 함께 담은 QuestionSet 하나가 됩니다. 리스트의 순서는 지면의 읽기 순서와 같고, 컬럼이나 페이지에 걸친 문항도 하나의 객체로 이어 붙어 돌아옵니다.

각 객체는 kdsnr_ai.ir 모듈의 pydantic 모델이고, JSON 구조와 1:1로 대응합니다. 모든 노드는 type 필드로 종류를 판별합니다. 문서 핸들이나 페이지 좌표 없이 내용과 구조만 담기 때문에, 파일로 저장해 두었다가 재사용하거나, 필드를 수정하거나, 처음부터 직접 작성할 수 있습니다.

  "metadata": {

    "subject": "korean",
    "q_nums": [38, 39],

  "passage": [

API 사용법

import_file

파일을 업로드하고 Document를 반환합니다.

from kdsnr_ai import Client, Document

client = Client(api_key="YOUR_API_KEY")

doc: Document = client.pipeline.import_file(
    "exam.pdf",
    label="exam_2026",
)
인자타입기본값설명
filestr | Path—파일 경로. .pdf · .hwp · .hwpx만 허용, 그 외는 ValueError.
labelstr | NoneNone문서 라벨. 생략하면 확장자를 뗀 파일명. 추출 결과의 metadata.label로 전파.

hwp · hwpx는 pdf로 변환되어 저장되며, source 링크는 이 pdf를 가리킵니다.

extract_question

문서에서 문항을 추출해 Question · QuestionSet 리스트로 반환합니다. EmitPreviewConfig 사용 여부와 관계없이, 파이프라인이 추출한 각 Question에는 100dpi WebP 이미지가 q_img 필드로 삽입됩니다.

from kdsnr_ai import Client
from kdsnr_ai.ir import Question, QuestionSet

client = Client(api_key="YOUR_API_KEY")

doc = client.pipeline.import_file("exam.pdf")

questions: list[Question | QuestionSet] = client.pipeline.extract_question(
    doc,
    subject="auto",
)

for q in questions:
    print(q.type, q.metadata.q_num, q.metadata.points)
인자타입기본값설명
docDocument—import_file이 반환한 문서.
subjectstr"auto"korean · math · social · science (별칭 kor · mat · soc · sci). auto는 문항 단위 자동 분류.
emit_overlayEmitOverlayConfig | NoneNone지정하면 검출 박스를 그린 pdf를 함께 반환.
emit_previewEmitPreviewConfig | NoneNone지정하면 추출과 동시에 선택한 형식의 문항별 미리보기 파일을 함께 반환.

emit_overlay와 emit_preview를 모두 생략하면 문항 리스트를 반환합니다. 둘 중 하나라도 지정하면 반환형은 ExtractResult입니다.

EmitPreviewConfig

q_img와 별도로 저장할 고해상도 이미지 · pdf · svg 파일을 추출과 동시에 만듭니다.

from pathlib import Path

from kdsnr_ai import Client, EmitPreviewConfig, ExtractResult

client = Client(api_key="YOUR_API_KEY")
doc = client.pipeline.import_file("exam.pdf")

result: ExtractResult = client.pipeline.extract_question(
    doc,
    emit_preview=EmitPreviewConfig(
        format="png",
        dpi=300,
    ),
)

for preview in result.previews:
    preview.save(Path("out/preview") / preview.filename)
필드타입기본값설명
formatstr"png"png · jpeg · pdf · svg.
dpiint300png · jpeg의 래스터 해상도. pdf · svg에는 적용되지 않습니다. 50~600 범위.

Question은 문항 영역이 파일 하나가 됩니다. 컬럼이나 페이지에 걸친 문항은 위아래로 이어 붙습니다. QuestionSet은 세트가 실린 페이지 전체가 반환됩니다.

EmitOverlayConfig

추출 결과에 반영된 요소를 클래스별 박스로 문서 위에 그려 받습니다.

from kdsnr_ai import Client, EmitOverlayConfig, ExtractResult

client = Client(api_key="YOUR_API_KEY")
doc = client.pipeline.import_file("exam.pdf")

result: ExtractResult = client.pipeline.extract_question(
    doc,
    subject="auto",
    emit_overlay=EmitOverlayConfig(
        classes=["inlinebox", "table", "cell"],
    ),
)

questions = result.questions
result.overlay.save("out/exam.overlay.pdf")
필드타입기본값설명
classeslist[str] | NoneNone그릴 클래스. None이면 전부. passage · instruction · question · eq · bogi · plainbox · inlinebox · bracket · table · figure · qnum · cell(표 격자). 그 외 이름은 오류.

ExtractResult는 questions, overlay, previews를 가집니다. 요청하지 않은 추가 결과는 None 또는 빈 리스트이며, Document.save(path)로 파일을 저장합니다.

0.1.x의 q_img_dpi · q_img 인자와 export_preview · ExportPreviewConfig는 기존 코드 호환을 위해 한시 지원되며, 사용 시 DeprecationWarning이 발생합니다.

compose_hwpx

Question 리스트를 한글 문서(hwpx)로 조판합니다.

from pathlib import Path

from kdsnr_ai import Client

client = Client(api_key="YOUR_API_KEY")

doc = client.pipeline.import_file("exam.pdf")
questions = client.pipeline.extract_question(doc)

paths: list[Path] = client.pipeline.compose_hwpx(
    questions,
    "out/hwpx",
)
인자타입기본값설명
questionslist[Question | QuestionSet]—조판할 문항. 추출 결과 또는 직접 작성한 객체 — id가 없어도 됩니다.
export_dirstr | Path—산출 파일 디렉터리.

문항·세트 하나가 hwpx 파일 하나가 됩니다. 결과물은 표준 서식으로 새로 조판된 문서이며, 원본 지면의 배치를 복원하지 않습니다.

Figure 입력

직접 작성한 문항에 그림을 넣을 때 Figure 블록에 쓰는 필드입니다. 그림 내용을 data에 직접 적거나, url로 주소를 가리킵니다. SVG로 적으면 좌표축 · 눈금 · 라벨이 적은 값 그대로 들어갑니다.

questions = [
    {
        "type": "Question",
        "metadata": {"q_num": 1},
        "content": [
            {"type": "Text", "text": "다음 그래프를 보고 물음에 답하시오."},
            {
                "type": "Figure",
                "format": "svg",
                "data": (
                    '<svg xmlns="http://www.w3.org/2000/svg" width="240" height="160">'
                    '<line x1="30" y1="130" x2="220" y2="130" stroke="black"/>'
                    '<line x1="30" y1="130" x2="30" y2="20" stroke="black"/>'
                    '<text x="120" y="148" font-family="1" font-size="10">시간 t (초)</text>'
                    "</svg>"
                ),
            },
        ],
    }
]

paths: list[Path] = client.pipeline.compose_hwpx(questions, "out/hwpx")
필드타입기본값설명
formatstr자동png · jpeg · webp · svg. 생략할 수 있습니다.
datastr""그림 내용. 이미지는 base64(data: 접두사 없음), SVG는 원문.
urlstr""공개 https:// 그림 주소. data와 둘 중 하나만 씁니다.
width heightfloat자동표시 크기(pt). 최대 폭은 단 폭 317pt입니다.

SVG 안의 글자는 본문과 같은 두 갈래로 지정합니다. 다른 글꼴 이름을 적으면 이 둘 중 하나로 바뀝니다.

font-family글꼴
"1"명조 — 지정하지 않을 때의 기본값
"2"돋움

hwp_to_pdf

hwp · hwpx 문서를 원본 조판 그대로 pdf로 변환합니다.

pdf_path: Path = client.pipeline.hwp_to_pdf(
    "exam.hwp",
    "out/exam.pdf",
    enable_vec=True,

인자타입기본값설명
filestr | Path—파일 경로. .hwp · .hwpx.
