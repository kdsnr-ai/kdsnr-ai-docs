Composer

Question 객체를 한글 문서로 조판하고, 문항 미리보기 파일과 한글 문서 변환 결과를 만드는 API입니다.

  • 입력 : Question 객체, 한글 문서 파일 (hwp, hwpx)
  • 출력 : 한글 문서(hwpx), 문항 미리보기 파일 (png, jpeg, pdf, svg), pdf
  • 표준 서식으로 새로 조판, 직접 작성한 Question 객체도 조판
  • hwp · hwpx를 원본 조판 그대로 pdf로 변환

개요

from pathlib import Path

from kdsnr_ai import Client

client = Client(api_key="YOUR_API_KEY")

doc = client.pipeline.import_file("exam.pdf")
questions = client.pipeline.extract_question(doc)

paths: list[Path] = client.composer.compose_hwpx(
    questions,
    "out/hwpx",
)
메서드역할
compose_hwpxQuestion 리스트 → 문항별 한글 문서(hwpx)
preview추출한 Question 리스트 → 원본 영역 미리보기 Document 리스트
export_preview추출한 Question 리스트 → 미리보기 파일 저장
hwp_to_pdfhwp · hwpx → pdf (원본 조판 보존)
hwp_to_hwpxhwp → hwpx

client.composer는 kdsnr-ai 0.3.0부터 제공됩니다. 0.2.x의 client.pipeline.compose_hwpx · hwp_to_pdf · hwp_to_hwpx · export_preview는 기존 코드 호환을 위해 같은 기능으로 계속 동작하며, 0.3.0에서 사용하면 DeprecationWarning이 발생합니다.

API 사용법

compose_hwpx

Question 리스트를 한글 문서(hwpx)로 조판합니다.

from pathlib import Path

from kdsnr_ai import Client

client = Client(api_key="YOUR_API_KEY")

doc = client.pipeline.import_file("exam.pdf")
questions = client.pipeline.extract_question(doc)

paths: list[Path] = client.composer.compose_hwpx(
    questions,
    "out/hwpx",
)
인자타입기본값설명
questionslist[Question | QuestionSet]—조판할 문항. 추출 결과 또는 직접 작성한 객체 — id가 없어도 됩니다.
export_dirstr | Path—산출 파일 디렉터리.

문항·세트 하나가 hwpx 파일 하나가 됩니다. 결과물은 표준 서식으로 새로 조판된 문서이며, 원본 지면의 배치를 복원하지 않습니다.

Figure.caption은 그림 아래에, Table.caption은 표 위에 가운데 정렬로 조판됩니다. Text.inlineimg 그림은 글자처럼 줄 안에 놓입니다.

Figure 입력

직접 작성한 문항에 그림을 넣을 때 Figure 블록에 쓰는 필드입니다. 그림 내용을 data에 직접 적거나, url로 주소를 가리킵니다. SVG로 적으면 좌표축 · 눈금 · 라벨이 적은 값 그대로 들어갑니다.

questions = [
    {
        "type": "Question",
        "metadata": {"q_num": 1},
        "content": [
            {"type": "Text", "text": "다음 그래프를 보고 물음에 답하시오."},
            {
                "type": "Figure",
                "format": "svg",
                "data": (
                    '<svg xmlns="http://www.w3.org/2000/svg" width="240" height="160">'
                    '<line x1="30" y1="130" x2="220" y2="130" stroke="black"/>'
                    '<line x1="30" y1="130" x2="30" y2="20" stroke="black"/>'
                    '<text x="120" y="148" font-family="1" font-size="10">시간 t (초)</text>'
                    "</svg>"
                ),
            },
        ],
    }
]

paths: list[Path] = client.composer.compose_hwpx(questions, "out/hwpx")
필드타입기본값설명
formatstr자동png · jpeg · webp · svg. 생략할 수 있습니다.
datastr""그림 내용. 이미지는 base64(data: 접두사 없음), SVG는 원문.
urlstr""공개 https:// 그림 주소. data와 둘 중 하나만 씁니다.
width heightfloat자동표시 크기(pt). 최대 폭은 단 폭 317pt입니다.

SVG 안의 글자는 본문과 같은 두 갈래로 지정합니다. 다른 글꼴 이름을 적으면 이 둘 중 하나로 바뀝니다.

font-family글꼴
"1"명조 — 지정하지 않을 때의 기본값
"2"돋움

preview

추출한 Question · QuestionSet의 원본 영역을 이미지 · pdf · svg 파일로 받습니다.

from pathlib import Path

from kdsnr_ai import Client, Document, PreviewConfig

client = Client(api_key="YOUR_API_KEY")

doc = client.pipeline.import_file("exam.pdf")
questions = client.pipeline.extract_question(doc)

previews: list[Document] = client.composer.preview(
    questions,
    PreviewConfig(
        format="png",
        dpi=300,
    ),
)

for preview in previews:
    preview.save(Path("out/preview") / preview.filename)
인자타입기본값설명
questionslist[Question | QuestionSet]—extract_question이 반환한 문항. metadata.q_id · metadata.set_id로 원본 영역을 찾습니다.
configPreviewConfig | NoneNone파일 형식과 해상도. 생략하면 300dpi png.

PreviewConfig

필드타입기본값설명
formatstr"png"png · jpeg · pdf · svg.
dpiint300png · jpeg의 래스터 해상도. pdf · svg에는 적용되지 않습니다. 50~600 범위.

Question은 문항 영역이 파일 하나가 됩니다. 컬럼이나 페이지에 걸친 문항은 위아래로 이어 붙습니다. QuestionSet은 세트가 실린 페이지 전체가 반환됩니다. 추출과 동시에 받으려면 extract_question의 emit_preview를 씁니다.

export_preview

preview 결과를 디렉터리에 바로 저장하고 저장한 경로를 반환합니다.

from pathlib import Path

from kdsnr_ai import Client, PreviewConfig

client = Client(api_key="YOUR_API_KEY")

doc = client.pipeline.import_file("exam.pdf")
questions = client.pipeline.extract_question(doc)

paths: list[Path] = client.composer.export_preview(
    questions,
    "out/preview",
    PreviewConfig(
        format="pdf",
        dpi=300,
    ),
)
인자타입기본값설명
questionslist[Question | QuestionSet]—extract_question이 반환한 문항.
export_dirstr | Path—저장할 디렉터리. 중간 디렉터리 자동 생성.
configPreviewConfig | NoneNone파일 형식과 해상도. 생략하면 300dpi png.

hwp_to_pdf

hwp · hwpx 문서를 원본 조판 그대로 pdf로 변환합니다.

from pathlib import Path

from kdsnr_ai import Client

client = Client(api_key="YOUR_API_KEY")

pdf_path: Path = client.composer.hwp_to_pdf(
    "exam.hwp",
    "out/exam.pdf",
    enable_vec=True,
)
인자타입기본값설명
filestr | Path—파일 경로. .hwp · .hwpx.
save_pathstr | Path—저장할 pdf 경로. 중간 디렉터리 자동 생성.
enable_vecboolTrueTrue=벡터 글리프 + 검색·복사 가능한 텍스트층. False=300dpi 래스터 페이지.

hwp_to_hwpx

구형 바이너리 hwp 문서를 hwpx로 변환합니다.

from pathlib import Path

from kdsnr_ai import Client

client = Client(api_key="YOUR_API_KEY")

hwpx_path: Path = client.composer.hwp_to_hwpx(
    "exam.hwp",
    "out/exam.hwpx",
)
인자타입기본값설명
filestr | Path—파일 경로. .hwp.
save_pathstr | Path—저장할 hwpx 경로. 중간 디렉터리 자동 생성.
